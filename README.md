# Global zero-excitation state preparation through subsystem cooling

Numerical code accompanying the paper by Kerstin Beer and Daniel Burgarth.

The code contains:
- full Liouvillian simulations for small spin chains
- convergence of the dynamical map
- single-excitation effective-Hamiltonian reduction
- comparison between the reduced and full Liouvillian gaps
- large-system scaling of the reduced gap estimate

## Requirements

Python 3
NumPy
SciPy
Matplotlib

## Usage

Run:

python main.py
